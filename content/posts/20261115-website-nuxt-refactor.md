从上一次网站重构日志发布开始到现在，这个网站又被大规模地重构了一遍。这次重构，我不仅把网站的技术栈换成了 Nuxt 4 + TypeScript + Tailwind CSS，还大改了网站的版式——从"顶栏+核心内容区域+双侧边栏"的 F 型布局，改成了"顶栏+核心内容区域+底栏"的 Z 型布局。在这篇文章里，我将详细介绍这次网站重构改了什么东西，以及分享自己在重构过程中的一些心得。

## 一、技术栈重构

这次技术栈更换的核心提交，是十月二十五日合并的那次迁移：从 VitePress 换到 Nuxt 4 + @nuxt/content v3 + Nuxt UI 4 + TypeScript + Tailwind CSS v4，构建方式改为 SSG 静态生成。

为什么要换？因为原来的技术栈定位错了。VitePress 本质是一台文档生成器，它的设计目标是"把 Markdown 转成好看的文档站"，能力天花板从一开始就画在那里。而这个网站要承载的东西早就超出了文档：博客归档、分类标签、站内搜索、评论系统，以及各种复杂交互。继续用文档生成器硬撑，等于让一个辅助位的选手去打核心输出——不是不能打，是每一局都在对抗自己的装备。

用竞技场的话说，这是一次换位：从辅助位换到法师位，整套装备跟着重配。Nuxt 4 提供完整的应用框架能力，@nuxt/content v3 接管内容库，Nuxt UI 4 负责组件层，TypeScript 保证类型安全，Tailwind CSS v4 用设计令牌统一视觉。静态产物的形态没变，能承载的上限变了。

## 二、样式和版式重构

技术栈换了，样式层自然全面接入 Nuxt UI 4——这不是把组件换一批，而是把整套视觉系统交给一套统一的设计语言托管。

版式上，我从"顶栏+核心内容区域+双侧边栏"的 F 型布局，改成了"顶栏+核心内容区域+底栏"的 Z 型三段式。旧版在桌面端靠两侧边栏塞辅助信息，信息密度看着很高，实际是让读者在三条纵向通道之间来回切换视线。新版回到正常的文档流：顶栏常驻，内容居中，底栏收尾，视野只剩一条主通道。

这次同时删掉了大量冗余代码：左右侧栏、抽屉手势、自建的滚动容器，以及成百上千行为了对抗旧框架而手写的样式。代码量和视觉复杂度是正相关的，砍掉一半冗余，页面反而更稳。首页重做为七个区块，游戏 ID 卡片从固定尺寸改成按数量决定滚动还是静止，搜索弹窗换用 Nuxt UI 的 UModal——这些都不是凭空新增的功能，而是把原本想要的效果，用更短的路径实现。

## 三、网站部署迁移到 Cloudflare Workers

部署也换了个地方。之前是 GitHub Pages 外配 Cloudflare CDN 加速，现在一次性迁到 Cloudflare Workers。

迁移后的部署形态是一个 assets-only Worker：静态资源托管在 Workers 上，自动处理 404 与 HTML 回退，生产与预览部署由 Cloudflare 连接 Git 后自动执行，Worker Previews 为每个分支提供预览地址。GitHub 那边只保留一条质量门禁——格式检查、lint、构建、产物校验；本地构建仍可用 wrangler 兜底。构建链一并重写：生成之后注入字体、再跑产物断言，nitro 预设锁死为 static，避免部署环境擅自切换预设。

换基地不是为了换而换。旧的托管方式要让静态站拿到理想的缓存与跨域行为，得靠一层又一层配置去补；迁到 Workers 之后，这些能力是默认的。少配一层，就少一处会出错的地方。

## 四、网站工具的迁出

和部署迁移同步，站内工具也搬了家。

原先工具页和首页的工具矩阵都在本站内，现在整套迁到独立的工具站 skystarlight.top，站内不再保留 /tools/ 路由和工具清单，顶栏的"工具"改为指向外站。导航数据统一成 href + external 结构：外链新标签页打开、自动补上安全属性与角标、不参与当前路由高亮，顶栏、移动下拉、底栏三处共用同一份数据。

这是分工。主站专注内容，工具站专注功能，两边各自把一件事做到位，比一个站点什么都塞要清楚。竞技场里也是这个道理——远程输出和近战承伤硬塞给同一个角色，两边都打不好。

## 五、其他增强

除主线之外，还补了几处细节。

字体改为产物自包含：HarmonyOS Sans SC 的三档分片在构建期灌注进产物，Cascadia Code 交给 Vite 打包，不再从 CDN 侧加载。等于自带补给上场，不依赖地图上的补给站——断网、CDN 抖动、跨域拦截，都不再是正文掉字体的理由。文章作者支持 frontmatter 自定义，缺省回退到站长；构建期自动生成网站地图，让搜索引擎能完整收录每一篇文章；产物校验在构建末尾逐条对账，把"该生成却漏掉"的页面挡在发布之前。搜索弹窗换用 UModal，正文站外链接统一新标签页打开，深浅色主题继续三态循环。

## 结语

从文档生成器到完整应用，从被两侧夹击的 F 型到一条主通道的 Z 型，从借来的托管到自己的基地——这次重构没有新增什么惊天动地的功能，做的其实是同一件事：把每一层放回它该在的位置。

系统工程的价值不在某一个炫目的功能，而在所有环节对齐之后，那种"什么都不用想就能跑"的稳定。这比多写一个特性难得多，也值钱得多。下的功夫都在看不见的地方，但每一分，都会在最关键的时候兑现。
